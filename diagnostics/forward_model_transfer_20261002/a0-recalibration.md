# A0 archive recalibration

The archived Newton A0 study was rescored using the multi-characteristic
diagnostic loss (loaded surface RMSE + 0.5×residual-footprint RMSE plus
normalized loaded volume, peak, and centroid terms). The archive contained 22
valid response maps; invalid trials were excluded.

The existing frozen incumbent remains the best A0 candidate:

- `log10(E)=4.847943757107725`
- `nu=0.23723150746162086`
- `mu=0.30549798022693525`
- multi-characteristic loss: `9.348518` (diagnostic units)

Thus the characteristic-aware A0 recalibration does not select a new material
point. The held-out A2–A6 results remain the decisive evidence: the selected
incumbent is admissible but its advantage depends on action location.
