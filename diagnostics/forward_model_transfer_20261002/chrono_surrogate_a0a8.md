# Expanded Chrono characteristic surrogate (A0–A8)

The baseline ridge surrogate was refit using nine accepted Chrono episodes,
adding the existing A0 and A1 mass points to A2–A8. Leave-one-out loaded
errors are:

| characteristic | RMSE |
|---|---:|
| mean depression | 0.378 mm |
| peak depression | 7.119 mm |
| depression volume | 126.471 cm³ |
| x centroid | 23.457 mm |
| y centroid | 2.347 mm |

Adding mass coverage improves the aggregate only slightly. The next GT data
should add independent spatial/geometry coverage (especially y offsets and
more radius values), not simply more repeats of the same guided center.
